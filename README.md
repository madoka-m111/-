## 2. 运行环境与一键复现

- Python 3.10+（本机 3.13），仅依赖标准库与 `matplotlib`；报告排版另用 `python-docx`，导出 PDF 用本机 Word。
- 复现实验中的四个任务，需要在项目根目录依次执行：

```powershell
python problem1.py
python problem2.py
python problem3.py
python problem4.py
```

- 对于实验中额外的对照实验与拓展，在项目根目录执行：

```powershell
python experiments.py
```

该命令依次完成：

1. 四题固定用例的基线输出（`results/baseline.json`）；
2. 迷宫：4 种规模 × 4 种密度 × 3 种启发式 × 12 个种子 = 576 组；
3. 加权地形：A/B 两种代价区间 × 25 个种子 × 4 种启发式，加 1 个构造反例 × 4 = 204 组；
4. Alpha-Beta：200 棵固定种子随机树 × 4 种访问顺序 = 800 次，另测默认树；
5. 综合题：7 个（地图, 深度）配置 × 24 次搜索 = 168 组；
6. 写出 `results/summary.json`、4 个 CSV 和 4 张 PNG。

本机完整运行约 **6.6 s**（最新一次 `summary.json` 的 `runtime_sec = 6.599`）。所有 Alpha-Beta 结果都与 Minimax 做断言，综合题还断言最佳目标一致；若断言失败，脚本会直接报错而不是静默记录。

## 3. 四个题目的测试用例（输入 / 预期输出）

### 3.1 题目一：迷宫寻路（`problem1.py`）

运行 `python problem1.py`，按提示输入。测试输入：

```text
(0,0)
(4,4)
[['S','.','.','X','.'],['.','X','.','.','.'],['.','.','.','X','.'],['X','.','X','.','.'],['.','.','.','.','E']]
<Ctrl+Z> 回车
n
```

预期输出要点：

- 路径：`[(0,0),(0,1),(0,2),(1,2),(1,3),(1,4),(2,4),(3,4),(4,4)]`
- 路径长度 `8`，总代价 `8`；
- 主程序使用曼哈顿启发式：`closed = 16`、`expanded = 17`、`open_max = 5`；
- 若在“是否进行启发函数性能对比”处输入 `y`，会额外输出 Dijkstra（closed 19）、欧氏（closed 16）的对比。

### 3.2 题目二：加权地形（`probiem2.py`）

运行 `python probiem2.py`，按提示输入：

```text
(0,0)
(4,4)
[['S','1','1','8','1'],['1','8','3','1','1'],['1','1','1','8','1'],['8','1','8','1','1'],['1','1','1','1','E']]
<Ctrl+Z> 回车
n
```

数字表示**进入该格**的代价，`S` 的进入代价为 1 但起点 `g(S)=0`，`E` 的进入代价为 0。预期：

- 最小总代价：`7`（不是步数 8）；
- 路径：`(0,0)→(1,0)→(2,0)→(2,1)→(3,1)→(4,1)→(4,2)→(4,3)→(4,4)`；
- 路径明细的 `g`：`0,1,2,3,4,5,6,7,7`；
- 曼哈顿/最小代价启发式：`closed = 11`、`visited = 19`；Dijkstra：`closed = 15`、`visited = 23`。

## 4. 对照实验与性能测试（`experiments.py`）

### 4.1 迷宫：启发式 × 规模 × 密度

- 变元：`n ∈ {21,31,41,51}`、密度 `∈ {0.05,0.15,0.25,0.35}`、`h ∈ {0, 欧氏, 曼哈顿}`；
- 12 个固定种子，每个配置 3 次取中位数；记录 `closed`、`expanded`、`open_max`、路径长度、耗时；
- 代表性结果（31×31、密度 0.25）：Dijkstra `closed=719.8`、`1.958 ms`；曼哈顿 `closed=429.0`、`1.258 ms`，节点少 **40.4%**、时间少 **35.7%**；
- 密度 0.05/0.15/0.25/0.35 的节点降幅分别为 6.8%/20.4%/40.4%/56.4%；规模 21/31/41/51 为 37.9%/40.4%/45.5%/47.0%。

### 4.2 加权地形：可采纳 vs 不可采纳

- A：数字格代价 2～9；B：1～9；每个 25 个种子；
- `h_min = c_min × 曼哈顿`，`h_2 = 2 × 曼哈顿`；
- A 上 `h_min` 把 `closed` 从 343.96 降到 327.56（**-4.8%**），25 个种子全部最优；
- B 上 `h_2` 把 `closed` 从 339.00 降到 305.84（**-9.8%**），但仍是 100% 最优——随机样本掩盖了不可采纳性；
- 构造 5×5 反例 C：`h_2` 返回 `58`，最优为 `56`，只扩展 11 个节点（最优启发式 20 个），首次同时展示“更快”和“更差”；
- 该反例证明 `2×曼哈顿` 不能作为加权地形的可采纳启发式；安全做法是 `c_min×曼哈顿`（并注意 `E` 的 0 代价边界）。

### 4.3 Alpha-Beta：访问顺序

- 200 棵均匀 3 叉、深度 4 的随机树，每棵 121 个节点；
- 四种顺序：原始、随机重排、2 层静态估值浅排序、最优排序（离线按子树真实值排序，仅作下界参考）；
- 平均访问：原始 69.18、随机 69.41、浅层 44.24、最优 37.00；
- 相对 Minimax（121）节省：42.8%、42.6%、63.4%、69.4%；
- 最优排序平均叶子 17，达到 Knuth-Moore 下界；浅层排序只比下界多 19.6%，但比原始顺序少 36.1%；
- 结论：随机打乱不提供信息；只有“先访问可能定界的子节点”才有收益。

### 4.4 综合题：深度 + 顺序

- 默认 7×7 与自设 9×9；`H=2～5`；
- 顺序：Minimax、AB 原始（T1→T4）、AB 随机 20 次、AB 增益排序（按 `value[t]-dist` 降序）、AB 最优排序；
- 默认 H=4：总节点 65，AB 原始 49，随机 43.25，增益 39，最优 31；增益比原始少 **20.4%**；
- 9×9 H=4：206 → 129 → 109.35 → 71 → 54；增益比原始少 **45.0%**；
- 9×9 H=5：326 → 208 → 172.40 → 116 → 76；
- 决策差异：H=2 选 T2（值 -1），H=4 选 T3（值 3）；H=3 仍选 T2，H=5 的值降到 -5，说明固定深度存在 horizon effect；
- 所有 AB 访问数都小于 Minimax，且最佳目标/价值与 Minimax 完全一致。

> 说明：毫秒级耗时受系统调度影响，报告中以**节点数**为主要性能指标；时间只作辅助。`closed` 与 `visited` 的口径不同：迷宫/加权统计 `closed`，博弈树统计 `nodes_visited`。
